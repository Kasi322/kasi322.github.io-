Основы UI и UX

Интерфейс связывает человека и систему. Пользователь выбирает действие, система обрабатывает его и показывает результат.

UI · User Interface

Элементы взаимодействия

Кнопки, подписи, поля, меню, звуки и другие средства управления. В магазине UI включает карточку товара, цену и кнопку «В корзину».

UX · User Experience

Опыт пользователя

Насколько легко выполнить задачу целиком. В магазине это поиск товара, понимание стоимости, оплата и уверенность, что заказ принят.

Виды интерфейсов

Эти категории могут сочетаться. Интернет-магазин на телефоне использует Web UI, графические элементы и сенсорное управление.

CLI — командная строка

Пользователь вводит текстовые команды, система отвечает текстом. Пример — терминал. Повторяемые задачи удобно автоматизировать, а новичку нужно выучить команды.

Тренажёр командной строки

Введите команду и нажмите Enter или выберите её ниже. Файлы в тренажёре вымышленные.

Учебный терминал
Введите help, чтобы увидеть команды.

Готово к запуску

Кнопка запускает действие. Флажок включает независимую опцию, а радиокнопки дают выбрать один вариант из группы. Ползунок меняет значение, индикатор показывает состояние операции.

Анализ приложений

Выберите два приложения с одной задачей. Задайте одинаковую стартовую точку, пройдите сценарий в каждом и запишите действия, ошибки и результат.

1. Задайте сценарий

Например, отправить готовую фотографию существующему контакту из списка чатов.

2. Зафиксируйте наблюдения

Запишите шаги, подписи кнопок и места, где пришлось искать подсказку. Добавьте скриншоты.

3. Предложите улучшение

Если кнопку отправки ищут, добавьте понятную подпись и повторите тот же сценарий.

Сравните два учебных приложения

Цель — найти альбом «Поездка» и открыть первую фотографию. Выберите наблюдение, которое поможет обосновать вывод.

Структура и навигация

Структура группирует экраны по назначению. Навигация связывает их переходами. Начните с цели пользователя, определите экраны, подпишите переходы и предусмотрите возврат после ошибки.

Карта интернет-магазина

Практическое занятие №1

Проанализируйте два существующих интерфейса и спроектируйте навигацию выбранной системы.

1. Сравните два приложения

Выберите пару с одинаковым назначением, например Kaspi и Halyk, Wildberries и Ozon или Telegram и WhatsApp. Пройдите один сценарий в обоих приложениях.

КритерийПриложение №1Приложение №2

Добавьте скриншоты, выберите более удобное приложение и обоснуйте выбор. Предложите три улучшения для каждого приложения.

2. Спроектируйте структуру приложения

Выберите интернет-магазин, электронную библиотеку, систему колледжа, сервис доставки или систему бронирования. Нарисуйте схему в Draw.io (diagrams.net).

  • Включите минимум восемь экранов и укажите переходы между ними.
  • Для каждого экрана опишите назначение и основные элементы интерфейса.
  • Покажите один полный сценарий от входа до результата.
  • Предусмотрите экран или сообщение об ошибке.
